RealtorDesk 0.1.18

What's new

- Linked client is now an optional dropdown inside the property editor on the Properties tab.
- Editing a property keeps its current client selected. Change or remove the assignment in the same window if needed.
- Removed the separate Property client popup after editing. Property details and assignment now save together when you press OK.
- New properties default to Unassigned. Editing a linked property from a client keeps the client-editor context.

Closed Price, notes, property addresses and existing client links are preserved.
