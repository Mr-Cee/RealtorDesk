RealtorDesk 0.1.28

What's new

- Client Status is now a dropdown: Lead, Looking for Home, Selling Home, Offered, Closed. New clients default to Lead.
- Property Status is now a dropdown: Listed, Offered, Closed. New properties default to Listed.
- Clients and Properties each have an Include closed checkbox, checked by default. Uncheck it to hide Closed records from both the list and live search.
- Common legacy statuses are converted: Sold to Closed; Pending, Under offer and Under contract to Offered. Active buyer/seller clients become Looking for Home/Selling Home. Other values use Lead/Listed; original converted values are retained in the database for reference.

Existing client links, addresses, MLS numbers, Closed Price values, commissions and documents are preserved.
