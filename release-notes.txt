RealtorDesk 0.1.12

What's new

- The Clients tab no longer displays the internal ID column. Linked records and client editing still use the IDs behind the scenes.
- New Date Last Communicated column for tracking your most recent contact with each client.
- Choose a date from a calendar in Add Client or Edit Client, with month/year navigation and a Today shortcut.
- Leave the date blank or use Clear to remove it. Dates display as YYYY-MM-DD and sort chronologically.
- Instant search includes communication dates alongside names, seller addresses and other client details.

Existing client records, seller address information, and linked documents, properties and calls are preserved. Existing communication dates start blank so you can enter the correct date.
