RealtorDesk 0.1.15

What's new

- Linked properties in Add/Edit Client: attach an existing unassigned property, create a new one, edit its details, or detach it.
- Create properties on the Properties tab without choosing a client. Edit or double-click a property later to assign, change, or remove its client.
- Property addresses and client links stay in sync across Clients and Properties. A client may have multiple properties; each property has one optional linked client.
- Existing seller addresses become linked property records during upgrade. Clients now show linked property addresses rather than a separate editable seller address.
- Client and property changes made in the client editor save together. Cancel leaves the existing records unchanged. Detaching keeps the property as an unassigned record.
- Key Dates and other existing client information are preserved.
