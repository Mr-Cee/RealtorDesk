RealtorDesk 0.1.24

What's new

- Settings now includes a Data folder chooser for the database, documents and other saved artifacts.
- Choose a separate empty folder and Save to copy and verify your data, update document links, and reload the app from the new location.
- The app remembers this folder for every startup and future update. Program installation location remains separate.
- Original files are retained as a fallback copy. Existing destination files are never overwritten.
- If a saved data folder is unavailable, startup reports the location instead of creating a new empty database.

Client records, property links, MLS numbers, Closed Price values and documents are preserved.
