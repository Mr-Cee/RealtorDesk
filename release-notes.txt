RealtorDesk 0.1.21

What's new

- Added an optional MLS # field to property information in both property-editing workflows.
- MLS numbers preserve leading zeroes and hyphens and appear in the Properties table.
- Added instant Properties search for any part of an address or MLS number, including multiword combinations.
- Search includes Clear, a matching count, and a no-matches message. Filtering remains active when records refresh.

Existing property information, linked clients and Closed Price values are preserved. Existing MLS numbers start blank.
